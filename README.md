# T3 — Regresión económica: CASEN y ENE

Responde a la pregunta: ¿Se asocia la edad con la probabilidad de tener un empleo
formal, y se mantiene esa asociación al comparar personas del mismo sexo y región?

Sí, la edad se asocia negativamente con la formalidad: cada año adicional se asocia
con 0,39 pp menos de probabilidad de tener un empleo formal. Esa asociación se mantiene
al comparar personas del mismo sexo y región, pues el coeficiente casi no cambia.
